\begin{frame}{Bayesian inverse planning}
\begin{columns}[T,onlytextwidth]

\begin{column}{0.48\textwidth}
\begin{block}{\faBrain\ Theory of mind as Bayes' rule}
\[
\belief{\Prob(\text{goal}\mid\text{action})} \;\propto\;
\Prob(\text{action}\mid\text{goal})\,\Prob(\text{goal})
\]
\begin{itemize}\tightitem
  \item likelihood: softmax-rational agent
  \item prior: plausible goals
\end{itemize}
\end{block}
\end{column}

\begin{column}{0.48\textwidth}
\begin{block}{\faHistory\ Earlier in this seminar}
\begin{itemize}\tightitem
  \item 03.12.: Bayesian ToM (Baker et al.)
  \item 17.12.: LLM-augmented inverse planning
  \item 14.01.: \texttt{memo} hands-on
\end{itemize}
\end{block}
\end{column}

\end{columns}

\slideendspace
\begin{alertblock}{\faLightbulb\ This paper}
Inverse planning is not used to \emph{read} minds, but as the \alert{audience model}.
\end{alertblock}
\end{frame}

  \item devices: one seed each, no human test
  \item one small grid world, 20 seeds per relation
  \item Exp.~2: small sample, N given as 35 and as 70
\end{itemize}

\begin{alertblock}{\faBalanceScale\ Claim vs.\ evidence}
Shown: the method \emph{can} make scenes that people read as intended.\\
Not shown: that human storytellers \alert{plan this way}.

\begin{frame}{Discussion}
\begin{enumerate}\tightitem
  \item The model makes readable scenes. What data would show that \emph{people} tell stories this way?
  \item Objective for Yu Tsun: which term makes the murder win?
  \item Is the Chief a Bayesian inverse planner? What prior does he need?
  \item Can the garden be optimized, or is refusing to choose the point?
  \item The arc objective \emph{penalizes} belief jumps ($D_{\mathrm{KL}}$). Should a twist \emph{reward} one?
  \item Could an LLM be the audience model? How would we test it? \seminar{Clever Hans risk: 05.11.}
\end{enumerate}

  \item $\Prob(s\to a\mid H)\propto\exp\big(\beta\, Q^H_c(s,a)\big)$
  \item value iteration, beam search, $T=15$
\end{itemize}
